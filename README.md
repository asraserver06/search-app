# 🍳 Gourmet Craft — Recipe Search & Discovery

> A modern, responsive web application for searching, discovering, and saving culinary recipes powered by **TheMealDB API**.

## 🚀 Live Demo

🔗 **Live Website:** https://gourmetcraft.netlify.app/

---

## ✨ Features

- 🔍 **Real-time Search with Debounce**: Search by recipe name or ingredient seamlessly.
- 🏷️ **Category Filtering**: Quickly filter recipes by Chicken, Beef, Pasta, Seafood, Vegetarian, Dessert, Breakfast, and more.
- 📖 **Interactive Recipe Modal**: View full ingredient lists, measurements, step-by-step instructions, and embedded YouTube cooking tutorials.
- ⭐ **Saved Favorites Drawer**: Bookmark your favorite recipes locally using `localStorage`.
- 📄 **Pagination & Page Size Control**: Smoothly paginate through search results with customizable page sizes.
- 📱 **Fully Responsive UI**: Mobile-optimized design with sticky navigation controls, custom scrollbars, and modern dark-mode aesthetic.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic structure and accessible markup.
- **Vanilla CSS**: Custom styling with CSS Variables, Flexbox, Grid, Glassmorphism, and dynamic animations.
- **JavaScript (ES6+)**: Modular logic, async/await fetch calls, debouncing, and DOM manipulation.
- **API**: [TheMealDB REST API](https://www.themealdb.com/api.php).
